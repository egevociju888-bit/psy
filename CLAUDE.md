# Greendiz Psy

WordPress-тема в папке `greendiz-psy`. PHP 8+, WP 6.4+, без сборки: CSS и JS лежат как есть в `css/` и `js/`.

## Git

- Коммитить и пушить сразу в `main`: без feature-веток и PR (решение владелицы, 2026-10-26).
- Перед пушем `git fetch origin main`; при расхождении сделать rebase.
- Сообщения коммитов короткие, на английском.

## Устройство

- Модули лежат в `inc/` и подключаются списком в `functions.php`.
- Версия ассета считается по `filemtime` (`gdpsy_asset_version`).
- Концепты (`inc/concepts.php`) и интерактивы (`inc/interactive.php`) рендерятся с оболочкой темы в shadow DOM.
- CSS для shadow DOM собирает `gdpsy_shadow_css` (`inc/enqueue.php`) из `styles`, `theme`, `concept`: заменяет `html` на `:host` и переименовывает шрифты. Новые селекторы вида `html[...]` в этих файлах проверять именно в этом контексте.

## Концепты и интерактивы

- Концепт лежит папкой `wp-content/concepts/<slug>/index.html`, интерактив: `wp-content/interactives/<slug>/index.html`. Старые одиночные `<slug>.html` не читаются.
- Остальные файлы (css, js, img, video) лежат рядом в любых подпапках и подключаются из `index.html` относительными путями.
- Тема переписывает относительные пути в `src`, `href`, `srcset`, `poster`, `data`, `url()` на адрес папки (`gdpsy_demo_html` в `inc/helpers.php`). Ссылки `<a>` и пути в `@import` не трогаются.
- Пути, которые JS собирает сам (`fetch`, `new Audio`, `img.src =`), считаются от адреса страницы. В таком коде брать адрес от скрипта: `new URL('x.json', import.meta.url)` в модулях, `document.currentScript.src` в обычных скриптах.

## Правила для интерактивов

Формулировки владелицы (2026-10-26) и контракт из `charisecarson/interactives` (`AGENTS.md`, `docs/interaction-contract.md`).

- Оформление: ориентир — старые интерактивы (шаблон `my-vdvoem`); берутся только шрифты и цвета сайта. Шрифты не подключаются: используются шрифты темы (`GDPSY Lora`, `GDPSY Onest`).
- Анимацию не отключать, `prefers-reduced-motion` не использовать.
- В кнопках нет диагональных стрелок. Ссылки на внешние источники в списках не затрагиваются.
- CSS пишется в один слой: правка идёт в существующее правило, без переопределений и дописанных блоков. Один селектор — одно правило на условие медиа. Неиспользуемые правила удаляются.
- Попапы (`dialog`) закрываются кликом по фону вокруг них.
- Копирование, сохранение, экспорт и ссылка на результат работают только с согласием: галочка снята по умолчанию, рядом раскрываемое пояснение, само действие — отдельная кнопка. Без согласия результат только показывается.
- Синий цвет выбора и светло-синий hover — правило для классических кнопок-вариантов. Другие оформления ответов (плитки с радио, чипы) допустимы.
- Результат теста не называется диагнозом. Источники только реальные и проверенные; использованные в тексте.
- Кнопка «Обсудить со специалистом» в демо-интерактивах может быть без действия.
- Разметка по таксономиям — отдельный шаг, начинается по запросу.
